# Molio pipeline illustrations

Six original images generated with the built-in image-generation tool for the main README. The artwork uses a consistent lavender, blue and mint 3D style. These are symbolic workflow illustrations, not actual molecules, protein coordinates, prediction results or screenshots.

The README uses six linked PNG cards in two rows, connected by arrows. Rounded borders, soft shadows, labels and arrows are baked into the rendered images, so they do not depend on custom README CSS or SVG embedding support. SVG sources retain accessible title and description text. The original generated artwork is unchanged.

Rebuild the frames and connectors with `python scripts/build_molio_pipeline_cards.py`, then render the PNGs with `python scripts/render_molio_pipeline.py` in an environment containing Playwright and Chromium or Google Chrome.
