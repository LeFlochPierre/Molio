# IsoForm demo for PowerPoint

Use **IsoForm-demo-1080p.mp4**: 54 seconds, 1920 × 1080 widescreen, H.264,
30 fps, about 3.4 MB. Captions are burned in. There is no audio, so you can
explain the demo while it plays. Download the MP4 to your presentation computer
and insert it as a local video. The other files are not needed for playback.

`poster.png` is an optional cover image for the video or a separate slide.

The video shows:

1. Molecule selection and actual prepared 3D pockets.
2. A fresh browser-launched UMA CPU run, with waiting accelerated.
3. The actual energy result, explicitly hypothetical fold proxy, and JSON export.
4. Separate saved-assay examples: an alert, a stronger assay ratio, and model disagreement.
5. Five-protein reference/input preparation and a downloadable input bundle.

The fresh UMA job is `0edea703248e`; all eight energy components completed.
It took about 163 seconds on CPU. Model output is exploratory, not validated
binding selectivity. Expanded-panel input generation is not a new prediction.

Traceability is saved in `recording.json`, `actual-uma-job.json`, and the
downloaded JSON/ZIP. The final MP4 was fully decoded to check its integrity.
The reusable recording script and storyboard are documented at
`scripts/video/README.md` in the project root.
