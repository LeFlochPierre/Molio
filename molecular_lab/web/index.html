    How do I edit a SMILES structure?

    SMILES describes atoms and bonds as text: C is carbon, O is oxygen, and parentheses introduce branches. Start with a small, deliberate change to the supplied structure. The preview checks syntax and valence; it does not establish that a compound can be made. A drawing editor is not included yet.
